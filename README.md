# NovexaHub

Premium frontend for [novexahub.live](https://novexahub.live) — a Pinterest-inspired digital services marketplace for ready-made websites, apps, ecommerce, AI automation, UI/UX, custom features and studio work.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo accounts

- Client: `client@novexahub.live` (any 6+ character password)
- Admin: `admin@novexahub.live` (any 6+ character password)

Favourites, checkout, orders and admin listings persist in `localStorage` for this frontend-only milestone.

## Stack

Next.js App Router, TypeScript, Tailwind CSS v4. Public pages are SEO-ready (metadata, sitemap, robots, JSON-LD). Motion is CSS-first with reduced-motion support.

Update the WhatsApp number in `src/data/site.ts` before launch.
