# Production domains — Cloudflare Worker + Hostinger registrar
# Main:  https://novexahub.live
# Admin: https://admin.novexahub.live  (opens /admin — sign in with novexahub.net@gmail.com)

# After the Worker is deployed, add the zone in Cloudflare (same account as Wrangler),
# then at Hostinger change nameservers to the two Cloudflare NS hosts.
# Cloudflare then creates:
#   @       CNAME  → Worker (proxied)
#   www     CNAME  → novexahub.live (proxied)
#   admin   CNAME  → same Worker (proxied)

# Firebase Auth → Authorized domains (add if missing):
#   novexahub.live, www.novexahub.live, admin.novexahub.live
#   novexahub.net, www.novexahub.net, admin.novexahub.net, localhost

# Local testing (macOS/Linux — edit /etc/hosts as admin):
127.0.0.1 novexahub.live
127.0.0.1 www.novexahub.live
127.0.0.1 admin.novexahub.live
127.0.0.1 admin.localhost

# Then:
npm run dev          → http://novexahub.live:3000 (main site)
npm run dev:admin    → http://admin.localhost:3001 (admin subdomain locally)
