## Specialist pages deliberately NOT created

| Keyword | Why skipped |
|---|---|
| Flutter App Development | Near-duplicate intent of `/mobile-app-development`; Flutter is the stated stack on that page. Revisit only if GSC shows distinct query demand. |
| Web Application Development | Overlaps `/web-development` + `/custom-software-development`; would be a doorway variant. |
| Workflow Automation | Subsumed by `/ai-automation` (workflow automation is a named offering there). |
| Marketplace Development | Evidence is thin (multi-vendor listed only as a custom-store capability); covered as a section of `/ecommerce-development`. |
| Industry pages (hotel/clinic/restaurant/real-estate) | Single-product evidence each → thin doorway risk. Catalog items carry the niche terms instead. |
| Location pages (USA/UK/CA/AU/DE/UAE/SA) | One global English site; no differentiated local proof, pricing or delivery info exists. Do not create without it. |

## Rules enforced on every page

- One unique title, description, canonical, and H1 per URL.
- Primary keyword used naturally in title/H1/first paragraph — no stuffing, no city-spin pages.
- Every page links sideways (sibling services), down (projects/posts) and to `/contact`.
- Structured data limited to what the page visibly claims (Organization, Service, BreadcrumbList, FAQPage, BlogPosting, CreativeWork, ItemList). No ratings/review schema.
